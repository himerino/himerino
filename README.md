## 🚀 Proyectos destacados

A continuación, presento una selección de proyectos que demuestran mi capacidad para aplicar tecnologías a problemas reales:

### 1. Explorando la cultura con la web
> **Problema que resuelve:** La necesidad de estructurar y presentar información cultural de manera accesible y estéticamente agradable en la web.
> 
> **Tecnologías utilizadas:** HTML, CSS, Git, Modelo Cliente-Servidor.
> 
> **Funcionalidades principales:** 
> * Despliegue de un sitio web estático multiplataforma.
> * Estructuración de contenido mediante etiquetas semánticas HTML.
> * Diseño e identidad visual gestionada enteramente a través de hojas de estilo CSS.
> 
> **Aplicación de lo aprendido:** En este proyecto se evidenció el rol del navegador y el servidor durante la solicitud/respuesta de recursos. Se aplicaron buenas prácticas de desarrollo al usar el control de versiones (Git) para gestionar la historia del sitio web, basándose en guías de aprendizaje estructural (HTML) y de apariencia (CSS).
> 
> 🔗 **[Ver Repositorio en GitHub](https://github.com/Fajard05/Proyecto-02-Explorando-la-cultura-con-la-web)**
### 2. AutoManager (App Móvil)
> **Problema que resuelve:** La gestión manual, desorganizada y lenta de las operaciones administrativas, servicios y facturación dentro de un taller mecánico.
> 
> **Tecnologías utilizadas:** Java, XML.
> 
> **Funcionalidades principales:**
> * Administración completa de entidades (Clientes, Proveedores, Técnicos y Servicios).
> * Generación de Órdenes de Servicios y Facturación Empresarial.
> * Generación automática de Reportes de Ingresos (por servicio general y por técnico específico).
> 
> 🔗 **[Ver Repositorio en GitHub](https://github.com/himerino/POO-P1-G04)**
### 3. Sistema de Facturación - Jardines de Esperanza
> **Problema que resuelve:** La ausencia de un sistema relacional optimizado para el registro de ventas y emisión de facturas por productos y servicios en un camposanto.
> 
> **Tecnologías utilizadas:** SQL (Bases de Datos Relacionales).
> 
> **Funcionalidades principales:**
> * Diseño e implementación de un modelo de base de datos relacional.
> * Registro histórico y seguro de facturación y transacciones comerciales.
> * Mapeo de relaciones complejas entre servicios contratados y clientes.
> 
> 🔗 **[Ver Repositorio en GitHub](https://github.com/himerino/Proyecto_SBD)**
